# Complete E-commerce Setup Guide\n\n## 🚀 Quick Start\n\n### 1. Start PocketBase Backend\n```bash\ncd Backend\n./pocketbase.exe serve\n```\n\n### 2. Setup PocketBase Admin\n- Open: http://127.0.0.1:8090/_/\n- Create admin account\n- Go to Settings > Import collections\n- Import `pb_schema.json`\n\n### 3. Add Sample Products\nIn PocketBase Admin > Collections > products > New record:\n\n**Product 1:**\n- name: Gaming Mechanical Keyboard\n- description: RGB backlit mechanical keyboard with Cherry MX switches\n- price: 129.99\n- category: keyboards\n- stock: 15\n- brand: TechPro\n\n**Product 2:**\n- name: Wireless Gaming Mouse\n- description: High-precision wireless gaming mouse with RGB lighting\n- price: 79.99\n- category: mice\n- stock: 25\n- brand: GameMax\n\n### 4. Start Frontend\n```bash\ncd frontend\nnpm install\nnpm run dev\n```\n\n## 🎯 Features\n\n### Customer Features:\n- ✅ Browse products with real-time data\n- ✅ Filter by category and sort by price\n- ✅ Add to cart with quantity management\n- ✅ Responsive design\n\n### Admin Features:\n- ✅ Full CRUD operations for products\n- ✅ Real-time product management\n- ✅ Inline editing in admin panel\n- ✅ Category management\n\n## 🔗 URLs\n- **Frontend**: http://localhost:5173\n- **PocketBase Admin**: http://127.0.0.1:8090/_/\n- **PocketBase API**: http://127.0.0.1:8090/api/\n\n## 📁 Project Structure\n```\nEcomApp/\n├── Backend/\n│   ├── pocketbase.exe\n│   ├── pb_schema.json\n│   └── pb_data/ (auto-created)\n└── frontend/\n    ├── src/\n    │   ├── components/\n    │   ├── pages/\n    │   ├── context/\n    │   ├── lib/\n    │   └── types/\n    └── package.json\n```\n\n## 🛠️ Tech Stack\n- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS\n- **Backend**: PocketBase (SQLite)\n- **State**: React Context API\n- **Icons**: Lucide React\n- **Routing**: React Router DOM\n\nThe application is now fully functional with real PocketBase integration!
